# longxiong.vip 搬到腾讯云操作手册

这份手册是给你（龙兄）照着点鼠标用的。技术上该干的我已经干完了，
你只需要在腾讯云控制台上点几下，把账号信息填回来。

---

## 一、为什么要搬

2026-09-02 实测，站点本身一点毛病没有，问题出在**托管它的地方**：

| 检查项 | 结果 |
|---|---|
| 域名解析（三家 DNS 交叉核对） | ✅ 全部正确 |
| GitHub Pages 官方状态页 | ✅ 无任何故障 |
| 国内网络直连 GitHub Pages 四个 IP | ❌ 三轮重试 0/4，全部超时 |
| 同一网络直连百度、腾讯 | ✅ 正常 |

**结论：国内网络连不上 GitHub Pages 的服务器，所以整站打不开。**
国外访问一切正常 —— 这就是为什么在电脑上偶尔能打开、手机上却死活打不开。

站点没问题，是"路"断了。搬到腾讯云就是换一条能走通的路。

---

## 二、搬家后的长什么样

```
现在：   Hugo构建 → 13个注入脚本 → 6道护栏 → 哈希 → Pagefind → 推到 GitHub Pages
                                                                    ↑ 这段路不通
搬后：   上面全不变 ─────────────────────────────────────────→ 上传到腾讯云 COS
                                                              ↓
                                                     CDN 加速（含 HTTPS）
                                                              ↓
                                                        访客
```

**构建流程一行没动**，只把最后一棒"发布"换了地方。前面十几道复杂工序一个字不改，
所以风险极低 —— 万一腾讯云那边出问题，GitHub Pages 这边的备份还在，随时能切回来。

> 实际上现在的代码是**两边同时发**：GitHub Pages 照常更新，腾讯云那边也同步一份。
> 你只要把 DNS 指过去就完成切换，中间不会有一秒钟网站打不开。

## 三、你需要做的（按顺序）

### 第 1 步：建一个存储桶（装网站的"硬盘"）

打开 https://console.cloud.tencent.com/cos5 → 「存储桶列表」→「创建存储桶」

| 配置项 | 填什么 | 为什么 |
|---|---|---|
| 名称 | 随便起，比如 `longxiong-site-1300000000` | 名字后半段是你的账号 ID，会自动带出来 |
| 所属地域 | **中国香港** `ap-hongkong` | ⚠️ 关键：没备案不能用大陆节点绑自定义域名。香港离大陆最近，速度最好 |
| 访问权限 | **公有读私有写** | 网站要能被所有人看到，但不能被外人改 |

> 等备案下来，再新建一个大陆地域的存储桶换过去，速度能从现在的水平降到 50~90 毫秒。

### 第 2 步：开启静态网站功能

进存储桶 → 左侧「基础配置」→「静态网站」→ 点「编辑」

| 配置项 | 填什么 |
|---|---|
| 当前状态 | **开启** |
| 索引文档（首页） | `index.html` |
| 错误文档（404 页） | `404.html` |
| 强制 HTTPS | 开（等证书配好再开也行） |
| 忽略 HTML 扩展名 | **不要开** —— 站内链接本来就都带 `.html`，开了反而会产生"同一个页面两个网址"的问题，对搜索收录不利 |

开完会给你一个网址，形如：
`https://longxiong-site-1300000000.cos-website.ap-hongkong.myqcloud.com`

先拿这个网址试一下，能打开就说明文件传对了。

> ⚠️ 官方文档特别提醒：必须用**自定义域名**访问才有静态网站效果，
> 用 COS 默认域名访问排版会是乱的。所以第 5 步的 CDN + 自定义域名不能省。
> （来源：腾讯云《设置静态网站》cloud.tencent.cn/doc/product/436/6249）

### 第 3 步：建一把专用钥匙（重要，别用主账号）

这是安全上的讲究：不要把你账号的万能钥匙交出去，单独配一把**只能操作这一个存储桶**的。

1. 打开 https://console.cloud.tencent.com/cam → 「用户」→「用户列表」→「新建用户」
2. 选「自定义创建」→ 勾选「**编程访问**」（只要这个，别开控制台登录）
3. 权限设置里，搜索并勾选 `QcloudCOSDataFullControl`，再把资源范围限定到刚建的那个存储桶
4. 建好后页面会显示 **SecretId** 和 **SecretKey** —— **SecretKey 只显示这一次**，立刻复制保存好

> 这样做的好处：万一这把钥匙泄露了，坏人也只能动这个网站的文件夹，动不了你账号里的其他东西。
> 真泄露了直接删掉这个用户就行，一秒钟止损。

### 第 4 步：把钥匙告诉 GitHub（填 4 个值）

打开 https://github.com/jinlong0221/personal-site/settings/secrets/actions → 「New repository secret」

一个一个填，共 4 个：

| Name（名字照抄） | Value（填什么） |
|---|---|
| `TENCENTCLOUD_SECRET_ID` | 第 3 步拿到的 SecretId |
| `TENCENTCLOUD_SECRET_KEY` | 第 3 步拿到的 SecretKey |
| `COS_BUCKET` | 存储桶名，比如 `longxiong-site-1300000000` |
| `COS_REGION` | `ap-hongkong` |

填完之后，**推一次代码**（或者随便改个文件提交推送），自动部署就会把整站同步到腾讯云。
去 GitHub 仓库的 Actions 页面看，有个步骤叫「Sync to Tencent Cloud COS」，变绿就成功了。

> 第一次是全量上传约 950 个文件，可能要几分钟。之后每天只传变动的几个，几秒钟搞定。

### 第 5 步：接 CDN（这一步才能用你自己的域名 + HTTPS）

打开 https://console.cloud.tencent.com/cdn → 「域名管理」→「添加域名」

| 配置项 | 填什么 | 说明 |
|---|---|---|
| 加速域名 | `longxiong.vip` | 你的域名 |
| 加速区域 | **中国境外** | ⚠️ 关键：官方明确写着"选择该区域时，对加速域名备案不作要求"。选「中国境内」或「全球」都必须要备案 |
| 源站类型 | COS 源 | 选你刚建的那个存储桶 |
| 计费方式 | 按使用流量计费 | 每月送 10GB，个人站一般用不完 |

（来源：腾讯云《从零开始配置 CDN》cloud.tencent.com/document/product/436/38062
及《域名接入常见问题》cloud.tencent.com/document/faq/243/43672）

添加完，CDN 会给你一个 CNAME 地址，形如 `longxiong.vip.cdn.dnsv1.com`。**记下来**，第 7 步要用。

### 第 6 步：配 HTTPS 证书（免费）

在 CDN 控制台 → 点刚加的域名 →「高级设置」→「HTTPS 配置」：

1. 点「申请免费证书」—— 腾讯云有免费的，按提示走就行（要验证域名归属，一般加一条 DNS 记录）
2. 证书下来后选中它
3. 打开「**强制跳转 HTTPS**」和「HTTP 2.0」

> 为什么这一步不能省：直接把自定义域名绑到 COS 上，用 https 打开会报证书错误。
> 必须走 CDN 才能正常上 HTTPS。

### 第 7 步：改 DNS（最后一步，改完就生效）

去你买域名的地方（阿里云）→ 域名解析设置，找到 `longxiong.vip` 的这条记录：

| 记录类型 | 主机记录 | 记录值 |
|---|---|---|
| CNAME | `@` | 第 5 步 CDN 给你的那个地址 |

`www` 那条如果也有，同样改成 CNAME 指向 CDN。

**生效时间**：快的话几分钟，慢的话几小时（各地运营商刷新有快有慢）。

## 四、怎么验证搬成功了

1. **手机关掉 WiFi，用流量打开** `https://longxiong.vip` —— 这是原来打不开的场景，能打开就算成功
2. 随便点几个页面，特别是 `/ev-sales.html`（新上的销量榜）和 `/herbs/chenxiang.html`
3. 试试搜索功能（右上角）—— 搜索走的是 Pagefind 索引，也一并传上去了
4. 地址栏看看是不是有个小锁图标（HTTPS 证书生效）

## 五、关于备案

**备案不是必需的** —— 本手册前面 7 步做完，你的站点在国内就能打开了（速度慢一点而已）。
如果你想追求 50~90 毫秒的国内极速，那就得备案。

### 备案的真实门槛（这是 2026-09-02 站长实测发现的坑）

腾讯云官方备案助手明说：「**当前账号下暂无可用于备案的云服务器或备案服务码，这是ICP备案的前置要求**」。

说人话：**你必须先在腾讯云有一台云服务器**（或从别人那里授权一个备案服务码过来），才能开始备案。

最低成本路径是买一台 **轻量应用服务器**（最小配置即可），然后用它产生的备案服务号去发起备案。
周期官方说法是 7~20 个工作日。

### ⚠️ 一个不能踩的坑：备案号与服务器绑定

备案下来后**那台服务器不能退订**。一旦退订，备案号会被注销（等于白忙）。
所以这是长期开销 —— 每年续费那台机器的钱。
预算紧张、或者还没感受到明显的速度问题，就先别启动备案，凑合用境外节点。

### 推荐节奏

```
现在      → 走第 1~7 步，国内能打开（稍微慢一点）
  ↓
用一段时间（1~2 周），真实感受一下速度
  ↓
觉得慢到影响体验  → 启动备案（买轻量服务器 + 走 7~20 天流程）
觉得还行          → 不动，保持现状
  ↓
备案下来 → 新建大陆存储桶 + CDN 加速区域改「中国境内」 → 50~90 毫秒
```

## 六、万一出问题怎么办

**Q：改了 DNS 之后打不开？**
A：先别慌。DNS 生效要时间。用这个命令看看解析走到哪了：
```bash
nslookup longxiong.vip
```
如果指向的还是 GitHub 的 IP（185.199.x.x），说明还没生效，等等再看。

**Q：打开了但排版是乱的？**
A：八成是用 COS 默认域名访问的。确认第 5、7 步都做了，必须用自定义域名访问。

**Q：想退回 GitHub Pages？**
A：把 DNS 记录改回去就行（CNAME 指向 `jinlong0221.github.io`）。
GitHub Pages 那边一直在同步更新着，随时能切回来，不会丢东西。

**Q：怎么确认腾讯云那边真的同步成功了？**
A：GitHub 仓库 → Actions → 看最新那次运行，找「Sync to Tencent Cloud COS」这一步。
日志里会写"比对完成：新增/变化 N 个，无变化 N 个"。

## 七、这次改了哪些代码

| 文件 | 作用 |
|---|---|
| `scripts/deploy_cos.py` | 新建。把构建产物增量同步到腾讯云的发布工具 |
| `.github/workflows/deploy.yml` | 加了一步「Sync to Tencent Cloud COS」，与原有 GitHub Pages 部署并存 |

**安全设计**：密钥只存在 GitHub Secrets 里，不进代码、不进日志。
**没配密钥时会安静跳过**（返回成功），所以没接腾讯云的人跑这条流程不会报错变红。
**但配了一半会报错** —— 这种"假绿"最坑人，CI 全绿可站点根本没更新，所以故意设成报错。
