# longxiong.vip 搬到腾讯云操作手册

这份手册是给你（龙兄）照着点鼠标用的。技术上该干的我已经干完了，
你只需要在腾讯云控制台上点几下，把账号信息填回来。

---

## 一、为什么要搬

2026-09-02 实测，站点本身一点毛病没有，问题出在**托管它的地方**：

| 检查项 | 结果 |
|---|---|
| 域名解析（三家 DNS 交叉核对） | ✅ 全部正确 |
| GitHub Pages 官方状态页 | ✅ 无任何故障 |
| 国内网络直连 GitHub Pages 四个 IP | ❌ 三轮重试 0/4，全部超时 |
| 同一网络直连百度、腾讯 | ✅ 正常 |

**结论：国内网络连不上 GitHub Pages 的服务器，所以整站打不开。**
国外访问一切正常 —— 这就是为什么在电脑上偶尔能打开、手机上却死活打不开。

站点没问题，是"路"断了。搬到腾讯云就是换一条能走通的路。

### 那要花多少钱？（先把账算明白）

**这是按量后付费，不用预存、不用包年，用多少算多少，不用就是零。**
跟第五章"买服务器备案"完全是两码事——那是一年几十上百的固定开销，
这个是一个月几块钱的水电费。别把两件事混在一起想。

**你的站点体量**（2026-09-02 实测 `public/`）：950 个文件，共 **45 MB**。
其中图片（webp）36 MB、HTML 7 MB。图片平均只有 56 KB，压缩得很好。

**① 存储费：约 0.007 元/月**

45 MB ≈ 0.044 GB，按 0.15 元/GB/月算，不到一分钱，可以忽略。

**② 流量费：月均几块钱**

CDN 官方刊例价（buy.cloud.tencent.com/price/cdn，首 2TB 档）：

| 加速区域 | 刊例价 |
|---|---|
| 中国境外·亚太1区（含中国香港，**不备案方案走这个**）| **0.46 元/GB** |
| 中国大陆（备案后才能用）| 0.21 元/GB |

按"每人看 5 个页面、每页连图带字约 0.3 MB"估（保守算法，实际有缓存会更低）：

| 月访问量 | 月流量 | 境外节点月费 |
|---|---|---|
| 500 人次 | 约 0.7 GB | 约 **0.3 元** |
| 2000 人次 | 约 2.9 GB | 约 **1.4 元** |
| 5000 人次 | 约 7.3 GB | 约 **3.4 元** |

> 表里是**估算**，按最费的方式算的。CDN 会缓存，第二次访问同一个页面
> 往往不重新下载图片，实际消耗通常比这更低。

**③ 关于"每月免费 10GB 流量包"**

⚠️ 这一条**官方定价页上没有**。腾讯云开发者社区的文章、代理商页面都在说
有 10GB 免费额度，但我核对官方定价页（buy.cloud.tencent.com/price/cdn）
没找到这句原文，所以**不敢当确定事实写**。

开通后自己在控制台的「费用中心 → 免费额度」看一眼，以实际显示为准。
如果确实有，上面这些数字还要再往下压——大概率就真的不花钱了。

**④ CDN 不收回源流量**

只有访客实际下载的那部分才计费。CDN 回你存储桶取内容的流量不收钱，
所以每天的自动构建推送不产生费用。

**一句话总结**：前面 1~7 步（不备案方案）跑起来，一个月大概**几块钱**，
量级上跟手机套餐的零头差不多。这笔钱跟第五章的备案开销不是一回事。

## 二、搬家后的长什么样

```
现在：   Hugo构建 → 13个注入脚本 → 6道护栏 → 哈希 → Pagefind → 推到 GitHub Pages
                                                                    ↑ 这段路不通
搬后：   上面全不变 ─────────────────────────────────────────→ 上传到腾讯云 COS
                                                              ↓
                                                     CDN 加速（含 HTTPS）
                                                              ↓
                                                        访客
```

**构建流程一行没动**，只把最后一棒"发布"换了地方。前面十几道复杂工序一个字不改，
所以风险极低 —— 万一腾讯云那边出问题，GitHub Pages 这边的备份还在，随时能切回来。

> 实际上现在的代码是**两边同时发**：GitHub Pages 照常更新，腾讯云那边也同步一份。
> 你只要把 DNS 指过去就完成切换，中间不会有一秒钟网站打不开。

## 三、你需要做的（按顺序）

### 第 1 步：建一个存储桶（装网站的"硬盘"）

打开 https://console.cloud.tencent.com/cos5 → 「存储桶列表」→「创建存储桶」

| 配置项 | 填什么 | 为什么 |
|---|---|---|
| 名称 | 随便起，比如 `longxiong-site-1300000000` | 名字后半段是你的账号 ID，会自动带出来 |
| 所属地域 | **中国香港** `ap-hongkong` | ⚠️ 关键：没备案不能用大陆节点绑自定义域名。香港离大陆最近，速度最好 |
| 访问权限 | **公有读私有写** | 网站要能被所有人看到，但不能被外人改 |

> 等备案下来，再新建一个大陆地域的存储桶换过去，速度能从现在的水平降到 50~90 毫秒。

### 第 2 步：开启静态网站功能

进存储桶 → 左侧「基础配置」→「静态网站」→ 点「编辑」

| 配置项 | 填什么 |
|---|---|
| 当前状态 | **开启** |
| 索引文档（首页） | `index.html` |
| 错误文档（404 页） | `404.html` |
| 强制 HTTPS | 开（等证书配好再开也行） |
| 忽略 HTML 扩展名 | **不要开** —— 站内链接本来就都带 `.html`，开了反而会产生"同一个页面两个网址"的问题，对搜索收录不利 |

开完会给你一个网址，形如：
`https://longxiong-site-1300000000.cos-website.ap-hongkong.myqcloud.com`

先拿这个网址试一下，能打开就说明文件传对了。

> ⚠️ 官方文档特别提醒：必须用**自定义域名**访问才有静态网站效果，
> 用 COS 默认域名访问排版会是乱的。所以第 5 步的 CDN + 自定义域名不能省。
> （来源：腾讯云《设置静态网站》cloud.tencent.cn/doc/product/436/6249）

### 第 3 步：建一把专用钥匙（重要，别用主账号）

这是安全上的讲究：不要把你账号的万能钥匙交出去，单独配一把**只能操作这一个存储桶**的。

1. 打开 https://console.cloud.tencent.com/cam → 「用户」→「用户列表」→「新建用户」
2. 选「自定义创建」→ 勾选「**编程访问**」（只要这个，别开控制台登录）
3. 权限设置里，搜索并勾选 `QcloudCOSDataFullControl`，再把资源范围限定到刚建的那个存储桶
4. 建好后页面会显示 **SecretId** 和 **SecretKey** —— **SecretKey 只显示这一次**，立刻复制保存好

> 这样做的好处：万一这把钥匙泄露了，坏人也只能动这个网站的文件夹，动不了你账号里的其他东西。
> 真泄露了直接删掉这个用户就行，一秒钟止损。

### 第 4 步：把钥匙告诉 GitHub（填 4 个值）

打开 https://github.com/jinlong0221/personal-site/settings/secrets/actions → 「New repository secret」

一个一个填，共 4 个：

| Name（名字照抄） | Value（填什么） |
|---|---|
| `TENCENTCLOUD_SECRET_ID` | 第 3 步拿到的 SecretId |
| `TENCENTCLOUD_SECRET_KEY` | 第 3 步拿到的 SecretKey |
| `COS_BUCKET` | 存储桶名，比如 `longxiong-site-1300000000` |
| `COS_REGION` | `ap-hongkong` |

填完之后，**推一次代码**（或者随便改个文件提交推送），自动部署就会把整站同步到腾讯云。
去 GitHub 仓库的 Actions 页面看，有个步骤叫「Sync to Tencent Cloud COS」，变绿就成功了。

> 第一次是全量上传约 950 个文件，可能要几分钟。之后每天只传变动的几个，几秒钟搞定。

### 第 5 步：接 CDN（这一步才能用你自己的域名 + HTTPS）

打开 https://console.cloud.tencent.com/cdn → 「域名管理」→「添加域名」

| 配置项 | 填什么 | 说明 |
|---|---|---|
| 加速域名 | `longxiong.vip` | 你的域名 |
| 加速区域 | **中国境外** | ⚠️ 关键：官方明确写着"选择该区域时，对加速域名备案不作要求"。选「中国境内」或「全球」都必须要备案 |
| 源站类型 | COS 源 | 选你刚建的那个存储桶 |
| 计费方式 | 按使用流量计费 | 每月送 10GB，个人站一般用不完 |

（来源：腾讯云《从零开始配置 CDN》cloud.tencent.com/document/product/436/38062
及《域名接入常见问题》cloud.tencent.com/document/faq/243/43672）

添加完，CDN 会给你一个 CNAME 地址，形如 `longxiong.vip.cdn.dnsv1.com`。**记下来**，第 7 步要用。

### 第 6 步：配 HTTPS 证书（免费）

在 CDN 控制台 → 点刚加的域名 →「高级设置」→「HTTPS 配置」：

1. 点「申请免费证书」—— 腾讯云有免费的，按提示走就行（要验证域名归属，一般加一条 DNS 记录）
2. 证书下来后选中它
3. 打开「**强制跳转 HTTPS**」和「HTTP 2.0」

> 为什么这一步不能省：直接把自定义域名绑到 COS 上，用 https 打开会报证书错误。
> 必须走 CDN 才能正常上 HTTPS。

### 第 7 步：改 DNS（最后一步，改完就生效）

去你买域名的地方（阿里云）→ 域名解析设置，找到 `longxiong.vip` 的这条记录：

| 记录类型 | 主机记录 | 记录值 |
|---|---|---|
| CNAME | `@` | 第 5 步 CDN 给你的那个地址 |

`www` 那条如果也有，同样改成 CNAME 指向 CDN。

**生效时间**：快的话几分钟，慢的话几小时（各地运营商刷新有快有慢）。

## 五、关于备案

**备案不是必需的** —— 本手册前面 7 步做完，你的站点在国内就能打开了（速度慢一点而已）。
如果你想追求 50~90 毫秒的国内极速，那就得备案。

### 备案的真实门槛（一句话）

**得先有一台"中国境内的腾讯云服务器"当门票。** 这台机器的用途只有这个——
你的网站内容还是放在香港存储桶里，它不跑网站。

目前有两条路能拿到这张门票，我们走第一条。

---

### 推荐路径（已拍板）：买一台轻量应用服务器

#### 为什么选这条路

| | 轻量应用服务器 | 现成的 CloudBase 环境 |
|---|---|---|
| 门槛 | 买 ≥3 个月即可 | 需同时满足三条（见下） |
| 现在的状态 | 没有，得花钱买 | 有，但**只剩 24 天有效期**，要手动续满 6 个月 + 开固定公网 IP |
| 成本 | 几十块/年 | 目前 CloudBase 个人版 ¥19.9/月，为备案还得续满半年 |
| 麻烦程度 | 买完就完事 | 续费时长有坑（自动续费按**当初开通时选的时长**续，选的是 1 个月，续完还是不够 6 个月，必须手动选更长的） |

**结论**：买台轻量服务器，一次性解决，比在 CloudBase 上凑条件省心。

#### 官方要求（cloud.tencent.com/document/product/850/18908）

> 轻量应用服务器（Lighthouse）：需购买腾讯云**中国境内**的轻量应用服务器，
> 计费模式为**包年包月**，购买**包月 3 个月及以上**（包含续费），
> 且**备案期间剩余有效期需大于（含）1 个月**。

拆开看就是四条，缺一不可：

| # | 要求 | 怎么满足 |
|---|---|---|
| 1 | **地域必须在中国境内** | 上海 / 南京 / 广州 / 北京 / 成都 任选。**千万别选中国香港或海外**——境外服务器不能用于备案（那个页面会提示"境外资源不在此列表中展示"） |
| 2 | **包年包月**（不能按量计费） | 购买页面默认就是这个，别手滑改了 |
| 3 | **购买时长 ≥ 3 个月** | 建议直接买 **1 年**，既满足要求，又能享受时长折扣 |
| 4 | **备案期间剩余有效期 ≥ 1 个月** | 买 1 年自然满足；要是只买 3 个月，审核拖久了可能卡线 |

补充两条官方口径：
- **个人账号**：同一台轻量服务器最多可备案 **5 个**网站/APP（本站只用 1 个，够）
- **备案本身不收费**，收的是服务器钱

#### 花多少钱

官方定价表（cloud.tencent.com/document/product/1207/73452），中国内地地域入门型：

| 配置 | 官方月价 | 买 12 个月（85 折） |
|---|---|---|
| 2核2G / 2M 带宽 / 100GB 月流量 | ¥35/月 | ¥357 |
| **2核2G / 3M 带宽 / 200GB 月流量** | **¥40/月** | **¥408** |
| 2核2G / 4M 带宽 / 300GB 月流量 | ¥48/月 | ¥490 |

> 时长折扣：1~5 个月无折扣，6~11 个月 88 折，**12 个月及以上 85 折**。

**但请先去活动页看一眼再下单。** 腾讯云常年有秒杀区，2026-09-02 查到的
「2026 采购季」活动页上写着：轻量应用服务器 **2核2G 3M、地域上海、时长 1 年，
活动价 ¥68**（页面标注日常价 ¥480），且标注「同价续费一次」。

**活动价变动很快，以你打开控制台时看到的实时报价为准。** 但不管哪档，
本手册建议的都是：**2核2G 起步够用，直接买 1 年**。
这台机器不跑网站，配置再高也是浪费。

> 镜像随便选一个 Linux（Ubuntu 或 CentOS 都行）。它不是拿来干活的，
> 只是备案的载体，装完放着就行。

#### ⚠️ 三个必须记住的坑

**1. 备案成功后，这台服务器不能退订。**

它是你备案的"根"。服务器一销毁，腾讯云和管局核查时发现"备案了但没有对应的
腾讯云资源"，备案号有被注销的风险（cloud.tencent.com/document/product/454/18908）。

所以这是一笔**每年几十块的长期开销**，买之前心理要有数。
好在这个价位的机器，留着当个远程小服务器用也值。

**2. 地域选错就白买。**

中国香港、新加坡、东京这些境外地域**一律不能备案**。下单时地域那一栏
看清楚是"中国内地"。

**3. 一个网站在备案表上只能填一个域名。**

本站现在的解析是 `www.longxiong.vip` 跳转到裸域 `longxiong.vip`，
实际对外服务的就是裸域。**备案时域名填 `longxiong.vip`（裸域）**，别填 www 那个。
填错了以后想改要走变更备案流程，麻烦。

---

### 第一坑：别从腾讯云"我的备案"进，那条路个人备案是死胡同

站长本人在 2026-09-02 实证踩过：腾讯云总备案入口（beian 控制台 → 我的备案 →
新增服务）的"云资源"那一栏只有三个选项：**云服务器 / 轻量应用服务器 / 备案授权码**。

**个人账号三选一全部撞墙**：
- **备案授权码** → 官方白纸黑字「**个人实名认证的腾讯云账号不允许生成备案授权码**」（cloud.tencent.com/document/product/243/49306）
- **云服务器** → 个人账号未购买，下拉里不会出现
- **轻量应用服务器** → 同上（**买完之后这里就会出现你的那台**）
- **CloudBase 环境** → **不在该列表展示**（页面会明确写「境外资源不在此列表中展示」）

**所以买了服务器之后，还是回到这个入口提交**——这时"轻量应用服务器"那一栏
就能选到你刚买的那台了。之前选不到，不是入口错了，是**没东西可选**。

### 备案流程（拿到服务器之后）

1. 轻量服务器**购买完成并开机**（一般 1~2 分钟）
2. 回到备案控制台：https://console.cloud.tencent.com/beian → 我的备案 → 新增服务
3. "云资源"选 **轻量应用服务器** → 下拉里应该能看到刚买的那台，选中
4. 按提示填域名（**填裸域 longxiong.vip**）、网站名称、个人资料
5. 腾讯云初审（1~2 个工作日）→ 短信核验 → 管局审核（1~20 个工作日）

> 备案期间网站该怎么跑还怎么跑——你现在的服务在香港节点，
> 境外服务本来就不要求备案，不受影响。

**备案号下来之后**，才轮到最后两件事：
- 新建一个**中国境内**的存储桶，把 `public/` 同步过去
- CDN 加速区域从「中国境外」改成「中国境内」，域名解析切过去

> 顺序不能反：境内 CDN 绑定自定义域名时，腾讯云会要求这个域名**已经备案**。
> 没备案号就配不了，所以是"先备案 → 再切境内"，不是反过来。

## 六、万一出问题怎么办

**Q：改了 DNS 之后打不开？**
A：先别慌。DNS 生效要时间。用这个命令看看解析走到哪了：
```bash
nslookup longxiong.vip
```
如果指向的还是 GitHub 的 IP（185.199.x.x），说明还没生效，等等再看。

**Q：打开了但排版是乱的？**
A：八成是用 COS 默认域名访问的。确认第 5、7 步都做了，必须用自定义域名访问。

**Q：想退回 GitHub Pages？**
A：把 DNS 记录改回去就行（CNAME 指向 `jinlong0221.github.io`）。
GitHub Pages 那边一直在同步更新着，随时能切回来，不会丢东西。

**Q：怎么确认腾讯云那边真的同步成功了？**
A：GitHub 仓库 → Actions → 看最新那次运行，找「Sync to Tencent Cloud COS」这一步。
日志里会写"比对完成：新增/变化 N 个，无变化 N 个"。

| 文件 | 作用 |
|---|---|
| `scripts/deploy_cos.py` | 新建。把构建产物增量同步到腾讯云的发布工具 |

**安全设计**：密钥只存在 GitHub Secrets 里，不进代码、不进日志。
**没配密钥时会安静跳过**（返回成功），所以没接腾讯云的人跑这条流程不会报错变红。
**但配了一半会报错** —— 这种"假绿"最坑人，CI 全绿可站点根本没更新，所以故意设成报错。
