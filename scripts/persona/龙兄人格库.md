# 龙兄人格库（Persona Library）

> 本库是 longxiong.vip「感情色彩 / 板块互通 / 自主更新的思考层」三件套的统一人格底座。
> **原则：只从龙兄本人已发布的文字里抽，不演绎、不代写。**

---

## 0. 这份库是干什么的

龙兄要的不是一个"更花哨的站"，而是一个**带着他本人脾气、各板块能互相串门、还能自己慢慢长大**的活站。
但目前站里：

- **板块互通**已建好（`build_related.py` 全站相关阅读），但只是算法配对，没有"龙兄本人"的味道；
- **感情色彩**只在紫砂页有雏形（`zisha_insight` 是领域知识推导，不是龙兄口气）；
- **自主更新**事实层已跑（二米的 `auto_update_*.py`），但缺"思考/连接"层。

这份人格库把龙兄的真实价值观、口气、忌讳、招牌比喻、各板块的真实态度抽成一份结构化档案
（`data/persona.json`），让上面三件事都能**对准同一个真实的龙兄**，而不是各编各的。

## 2. 龙兄的口气（voice）

- **大白话**：用日常口语，不爱堆术语；术语先翻译成人话。
- **坦诚直给**：敢说"我错了 / 我懒了 / 我脸红"。
- **较真但不端着**：有原则，但像朋友聊天。
- **慢热克制**：不追热点、等终稿/官方确认。
- **带人情味**：把站当"家 / 壶 / 外挂大脑"来养。
- **偶尔自侃**：公示牌里会冒"龙兄王者归来""举国欢庆"。

**招牌比喻（也都在库里，可当引用素材）**
- 紫砂包浆 / 养壶 → "这站本身也像一把壶——慢慢养，才有光"
- 家要常收拾 → "站和家一样，得经常收拾才住得舒服"
- 外挂大脑 → 网站最早是自己的外挂大脑
- 信息坟场 → 只进不出会变坟场，所以要定期淘汰
- 托付 → 读者交出的时间与数据是托付，亏不起

## 3. 红线（生成器必须当护栏，违反即判失败）

1. **绝不代龙兄编造第一人称日记 / 观点** —— 任何"龙兄怎么看"只能是草稿，龙兄过目才发。
2. 绝不用 AI 图冒充实拍。
3. 绝不编造 URL / 用打不开的链接充数。
4. 绝不写"官方资料 / 维基百科 / 媒体报道"这类无法核验的笼统表述。
5. 绝不营销 / 带货 / 接软文 / 放联盟链接。
6. 不确定 / 未来节点必须标"待官方确认"，绝不替它把日子定了。
7. 工具绝不上传 / 不联网 / 不碰别人的作品。
8. 养生 / 紫砂 / 游戏等内容必须明示不构成医疗 / 投资 / 法律建议。

## 4. 各板块的真实态度（board_attitudes）

库里给每个主板块记了：`stance`（龙兄的态度，第三人称摘要）、`pull_quote`（龙兄**本人原话**，带出处）、
`persona_links`（该板块该挂接哪些"龙兄第一人称页"：手记 / 关于 / 方法论 / 踩坑 / 读书 / 隐私）。

**用法铁律**：生成"龙兄视角"区块时——
- 要么直接**引用** `pull_quote`（这是龙兄原话，安全）；
- 要么只**挂链接**到 `persona_links` 里的真实页面（标题用页面真名）；
- **绝不**把 `stance` 当成龙兄的口吻去自由造句。

---

## 5. 发布前必须过的一道关（review_policy）

- 所有以"龙兄"口吻成段的文字，生成器只产出 `status: draft` 的草稿；
- 发布前**必须由龙兄本人过目确认**，绝不自动上线；
- 凡涉及龙兄观点的生成，必须挂接 `persona_pages` 真实链接，不得凭空造句；
- 宁可少关联、少发声，也绝不为了"互通"编造龙兄没说过的话。

---

## 6. 文件清单

- `data/persona.json` —— 机器可读人格档案（生成器消费它）。
- `scripts/persona/龙兄人格库.md` —— 本说明（人读）。
- `scripts/build_persona_links.py` —— 互通层扩展：给各板块页注入"龙兄视角"aside（引文+真实链接，安全）。
- `scripts/gen_persona_draft.py` —— 思考层草稿：把一次自动更新事件翻成"龙兄怎么看"草稿（仅草稿，待审）。
