# 龙兄口头指令清单（对我直接说的暗号）

> 用途：这是一份「你（龙兄）在对话里直接对我说的话 → 我该干什么」的约定表。
> 凡是命中下面任意一条「暗号」的消息，我都会照做，不会当成闲聊漏掉，也不会反复跟你确认。
> 维护人：AI 副驾（本对话）。改这条约定本身，请直接说「更新指令清单」。

---

## 0. 总原则（先记住）

- **文案照搬、不润色**：你说过的话，挂状态、写手记都原样引用，不替你改口吻。
- **不编第一人称**：凡是「龙兄怎么看 / 站长手记」类成段文字，只引用你已发布的原话 + 真实链接，绝不替你编观点。
- **不花钱、纯前端**：现阶段后端、云服务、付费接口一律不考虑（你明确说过网站不盈利、不想额外花钱）。
- **不生成 AI 图**：要用图就用真实实拍 / 公开可核验来源，绝不用 AI 画图冒充实拍。
- **改完要可验收**：任何改动都跑守卫、自查、提交并等 CI 绿，最后给你一句话结论。

## 1. 挂站点状态（最高频）

| 你说的话 | 我做什么 |
|---|---|
| 消息以 **「状态：」** 开头，例如 `状态：今天把紫砂板块理顺了` | 把冒号后的原话挂到站点状态牌（导航气泡 + 站点状态页），自动带当天时间 |
| `状态：刚跑完步 🏃` | 同上；若正文里带 emoji（如 🏃）就用作状态图标，没有就沿用上一条图标 |
| `状态：手头事多，勿扰` 或含「非诚勿扰 / 别打扰 / 勿cue / 免打扰」 | 挂状态并把「勿扰」标为 true（状态页会显示请勿打扰） |
| `挂：……`（同「状态：」） | 等价于「状态：」，兼容写法 |

- 底层脚本：`scripts/set_status.py`（自动剥前缀、取 emoji、标勿扰、重建历史、提交推送）。
- 历史查看：站点「站点状态」页（`status-history.html`）。

---

## 2. 写 / 改「站长手记」

| 你说的话 | 我做什么 |
|---|---|
| `帮我写篇关于 XX 的手记` / `记一笔：……` | 起草一篇手记，严格引用你给的素材或已发布内容；**先给你过目，不自动发布** |
| `把这篇手记发上去` | 经你确认后，写入 `content/notes.md` 并走发布流程（含 changelog、守卫、提交） |

- 红线：手记里任何「龙兄视角」的成段观点，必须来自你本人已说/已写，不代写。
- 草稿先出状态 = `draft`，你拍板才转正式。

---

## 3. 总结 / 盘点某个板块或主题

| 你说的话 | 我做什么 |
|---|---|
| `总结一下 XX 板块` / `帮我盘点下紫砂` | 拉取该板块真实内容，出一份「现状 + 亮点 + 待补」的盘点（引用真实链接） |
| `最近站点都更新了啥` | 读 `changelog` / `status-history` 给你一份近期更新摘要 |
| `把 XX 和 YY 打通` | 在相关页互相加「相关阅读」入口（用 `build_related.py` / `apply_related.py`） |

---

## 4. 审计 / 排查站点

| 你说的话 | 我做什么 |
|---|---|
| `审计一下站点` / `全面检查 XX 板块` | 跑 `scripts/audit_regression.sh` 自动项 + 逐条过 `AUDIT_REGRESSION.md` 人工项；带历史问题一起查，不漏项 |
| `XX 页面好像有问题` | 定位具体页，查结构 / 样式 / 守卫，给结论 + 修复方案 |
| `排版有点别扭` | 审查该页布局、配色、移动端，给「硬结论（代码验证）+ 手感建议（推断）」两类建议 |

- 审计铁律：自动项先跑 → 人工项逐条过 → 本轮新修问题当场补登记表 → 汇报写清「跑了哪些、过了哪些、有无新增」。

## 5. 改页面 / 加板块 / 加工具

| 你说的话 | 我做什么 |
|---|---|
| `给 XX 板块加个 XX 功能` | 评估后动手，纯前端优先（无后端、不花钱），复用全站国风黑金与 A9 骨架 |
| `加个问龙兄的页面` | 走「纯前端问答」路线：预置 `ask-kb.json` + 客户端关键词匹配，GitHub Pages 托管，不露密钥 |
| `导航加个 XX 入口` | 改 `layouts/partials/navbar.html` 单一数据源 → 跑 `sync_navbar.py` 全站同步 |
| `这个板块配色不对` | 修 CSS（权威文件 `static/css/style.css`），注意全站国风金身份，避暖色调刺眼 |

## 6. 维护「问龙兄」问答知识

| 你说的话 | 我做什么 |
|---|---|
| `问龙兄里加一条：……（问法 + 回答）` | 把这条写进 `static/ask-kb.json`（问法 + 触发词 + 龙兄口吻回答 + 真实链接） |
