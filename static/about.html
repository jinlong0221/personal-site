📖 网站简介

「龙兄知识库」是由 AI 辅助搭建 的个人知识分享网站，记录站长在生活、兴趣与折腾过程中的学习笔记和实用经验。

内容涵盖紫砂艺术、沉香鉴别、中药材、养生茶、数码科技、流行文化等领域，力求 实用、靠谱、可落地。

🎯 建站初衷

这个网站最初只是我自己的「外挂大脑」——把生活里反复踩过的坑、亲手验证过的经验记下来，下次不再被同一个问题坑第二次，也顺手分享给可能遇到同样问题的人。

  • 实测溯源，不搬运二手结论。站里能亲手测的内容，我一定先自己跑一遍、拍下来、记下环境与结论；引用他人结论会标出来源并尽量交叉核对，不当「复制粘贴机器」。
  • 不营销、不带货、不接软文。全站没有任何商业推广、联盟链接或付费内容。推荐的店铺或商品只是个人经历，不构成购买建议——这与营销号的根本区别就在这里。
  • 长期主义，慢就是快。内容少而精，宁可少写也不编。能帮一个人省下真金白银或半天折腾，这个站就有价值。

🔄 更新规则与内容创作标准

为了让「实测溯源」不只是口号，本站内容遵循以下硬规则：

更新频率

  • 资讯类板块（新车 / 新机 / 票房 / 天气等）每日自动刷新，保证数据不过期；
  • 深度原创随研究进度发布，不求日更，但求每篇经得起复核。

内容创作标准（六条）

  1. 一手实测优先：能亲手测的必亲手测，记录测试时间、环境、样本与结论，并附实拍图。
  2. 多源交叉验证：政策、参数、数值类信息须 ≥2 个独立可信来源；单一来源须明确标注。
  3. 事实与观点分开：主观体验明确标注「本人一手记录」，并声明不构成医疗 / 投资 / 法律建议。
  4. 标注时效：价格、参数、档期等易变信息标注「截至时间」；无法确认的未来节点标注「待官方确认」。
  5. 可复核：关键数据附出处链接；遇反爬 / 403 域名只写文本、不做超链，不做断章取义。
  6. 公开纠错：发现错误立即修订并记入更新日志，不悄悄改、不删帖掩盖。

本站不参与：商业推广、联盟带货、付费软文、未经验证的「内幕消息」。

🛠️ 开源仓库与二次部署教程

本站是纯静态站点，代码以 MIT 许可、内容以 CC BY-NC 4.0 许可完全开源，任何人都可以 fork 后部署成自己的知识库。

  • 仓库地址：github.com/jinlong0221/personal-site
  • 技术栈：Hugo（静态生成）+ Pagefind（站内搜索）+ GitHub Pages（托管），无后端、无数据库。

本地预览

# 1. 安装依赖：Hugo extended、Git、Node（供 Pagefind）
# 2. 克隆仓库
git clone https://github.com/jinlong0221/personal-site.git
cd personal-site

# 3. 本地预览（默认 http://localhost:1313）
hugo server -D

# 4. 生成静态文件到 public/
hugo --gc

部署到 GitHub Pages

  1. Fork 本仓库到你的 GitHub 账号；
  2. 修改 hugo.toml 里的 baseURL 为你自己的域名（或用默认的 username.github.io）；
  3. 写文章：放到 content/（Hugo 文章），或直接编辑 static/ 下的页面；
  4. 推送 git push origin main，GitHub Actions 自动执行 hugo --gc + Pagefind 并推送到 gh-pages 分支；
  5. 仓库 Settings → Pages → Source 选择 Deploy from a branch → gh-pages / root，约 1–2 分钟生效；
  6. 自定义域名：在 Settings → Pages → Custom domain 填写，并在仓库根目录添加 CNAME 文件即可。

提示：仓库内置「旅行加密」等可选脚本（依赖 TRAVEL_KEY 仓库密钥），二次部署时如不需要可忽略；其余板块开箱即用。
