低谷 平段 高峰 尖峰

电价随尖峰 / 高峰 / 平段 / 低谷浮动，同一根枪白天和半夜能差近一倍。上图按一般规律标注，仅供参考，实际以各运营商现场公示为准。

📖 价格是怎么来的？先说清楚

  • 充电桩的电费不是一口价。一度的总价 = 电费 + 服务费，而且按尖峰 / 高峰 / 平段 / 低谷分时段浮动，同一根枪白天和半夜能差一倍。
  • 实时电价属于运营商的商业数据，国家电网、特来电、星星充电等都不对外提供数据，只能在其自家软件里，或高德、百度地图里查看。所以本页的做法是：能核到价的直接显示，核不到的明写"以现场为准"并给一键跳转按钮，绝不编数字。
  • 本页标注「本站核实」的价格，来自政府公开文件、运营商公开页面或本站实测，并注明采集时点；其余一律点「查实时价」跳到高德地图看当前真实价格。
  • 省钱小提示：大部分地区的低谷时段在 23:00–次日 7:00，此时充电通常最便宜；高速服务区充电桩价格普遍高于市区；商场停车场的桩常有"充电免停车费"优惠。
