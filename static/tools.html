工具箱

十个纯浏览器小工具——图片压缩、格式转换、尺寸与 DPI、图片转 PDF、批量加水印、长图拼接、EXIF 查看与清除、取色配色板、二维码生成、音频转 WAV。
所有文件都在你自己的设备里处理完，不上传、不联网、不留存，断网也能照常用。

使用前请知悉
  • 文件全程在你自己的设备上处理，不上传、不保存、不联网；关掉页面即清空，服务器上什么都不会留下。
  • 本站不提供任何平台的视频/音频解析，不提供去水印，不绕过任何平台的内容保护措施；所有功能都只做格式、尺寸、元数据这一类基础变换。
  • 请仅用于你拥有合法权利的文件。其中批量加水印与清除 EXIF 请勿用于处理他人作品（抹去他人作品的版权与作者信息可能构成侵权）。
  • 本站无账号、不收费、无使用次数限制。工具为个人自研，若发现异常请通过页脚邮箱反馈。

点这里选音频 或拖进来 · 可多选 · MP3 / M4A / AAC / OGG / WAV / FLAC

关于这些工具

为什么只有这十个
  • 能做的、该做的，其实是「只在你自己的设备上，把你自己文件的格式/尺寸/元数据变一变」这一类。凡是需要拿别人平台内容的（视频解析、去水印）、需要由我向公众生成内容的（AI 改写、语音转写）、或者会绕开平台限制的，本站一律不做——这不只是技术取舍，也是法律边界。
  • 视频压缩没有放进第一批：它需要下载约 30 MB 的本地编解码引擎，而在 GitHub Pages 这类静态托管上拿不到多线程所需的响应头，体验会明显打折。宁可先不做，也不给你一个半成品。
  • 所有功能都没有联网请求，你可以打开浏览器开发者工具的 Network 面板自行验证：从头到尾不会有一条对外请求。
  • 工具会在后续继续补充。你希望下一个是什么，欢迎写信告诉我。

本站内容为个人整理与实测记录，仅供参考；涉及外部数据以正文标注的来源为准。
